# Network-Intrusion-Detection-Lab-study-Snort
Teamwork Academic laboratory project focused on Network Intrusion Detection Systems (NIDS) and network security. 
Designed and implemented a virtual network environment using VMware Workstation and Linux virtual machines. The project included network reconnaissance and port-scanning experiments using Nmap, configuration of Snort as a Network Intrusion Detection System, development of custom detection rules, alert generation, logging and analysis of network traffic.

Technologies: Linux, Snort, Nmap, VMware Workstation, TCP/IP, Network Security, IDS/NIDS, Network Traffic Analysis.

Legacy academic project preserved for educational and historical purposes.
